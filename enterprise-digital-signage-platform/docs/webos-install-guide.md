# 📺 คู่มือติดตั้งจอบน LG webOS TV (ฉบับช่าง)

คู่มือนี้สำหรับ **คนติดตั้งจอ (ช่าง/เจ้าหน้าที่)** — ทำตามทีละขั้นได้เลย
ใช้กับ **ทีวี LG รุ่น webOS 24 (9.x) ขึ้นไป** เช่น webOS `9.2.2-2404`

> รายละเอียดเชิงเทคนิค (build .ipk, auto-start, API) ดูเพิ่มที่
> `webos-player/README.md` — คู่มือนี้คือขั้นตอนภาคสนาม

## 0. สิ่งที่ต้องเตรียม

| ของ | รายละเอียด |
|---|---|
| ทีวี LG webOS 24+ | จอที่จะติดตั้ง |
| **คอมพิวเตอร์** สำหรับติดตั้งครั้งเดียว | Windows/Mac + ติดตั้ง **webOS Dev Manager** (ดูข้อ 2) |

## 1. เปิด Developer Mode บนทีวี (ครั้งเดียว)

> ⚠️ **ทำก่อนติดตั้งแอปเสมอ** — ถ้าไม่เปิด โหลดแอปเข้าจอไม่ได้

1. เปิดทีวี → เข้า **LG Content Store** (ปุ่ม Store บนรีโมท)
2. ค้นหา **Developer Mode** → กดติดตั้ง
3. เปิดแอป Developer Mode → ล็อกอินด้วย LG developer account
4. กดเปิด **Dev Mode Status: ON** → ทีวีจะรีบูตเอง
5. หลังรีบูต → เปิดแอป Developer Mode อีกครั้ง → **จำ IP ของทีวี + Passphrase** ไว้
   (หน้าจอจะแสดง 2 ค่านี้)

> ⚠️ Dev Mode มีอายุจำกัด (~1,000 ชั่วโมง) — เมื่อใกล้หมด เปิดแอป Developer Mode
> เพื่อต่ออายุ **ห้ามปิด Dev Mode** ระหว่างใช้งาน (แอปที่ติดตั้งไว้จะถูกลบ)

## 2. ติดตั้งแอปลงทีวี (ใช้คอมฯ ครั้งเดียว)

### 2.1 ติดตั้ง webOS Dev Manager บนคอมฯ

ดาวน์โหลดจาก https://github.com/webosbrew/dev-manager-desktop/releases
(เลือกตัวติดตั้งตามระบบของคอมฯ — Windows/Mac/Linux)

### 2.2 เชื่อมต่อคอมฯ กับทีวี

1. เปิด webOS Dev Manager → แท็บ **Devices** → ปุ่ม **+**
2. กรอก **IP ของทีวี** (จากข้อ 1.5) → กด Connect
3. ถ้าถาม **Passphrase** → กรอกจากข้อ 1.5

### 2.3 ติดตั้งแอป

1. แท็บ **Apps** → ปุ่ม **Install app…**
2. เลือกไฟล์ **`com.nextgen.webos-player_1.0.0_all.ipk`** (รับจากทีมพัฒนา)
3. รอจนขึ้น "Installed" → แอปจะปรากฏในหน้า Home ของทีวี (My Apps)

---

## 3. ตั้งค่าครั้งแรกบนทีวี

1. เปิดแอป **NextGen Signage Player** บนทีวี
2. หน้าแรก: กรอก **Server URL** เช่น `http://10.70.0.1:3100`
   → กด **ทดสอบการเชื่อมต่อ** → ควรขึ้น "✓ เชื่อมต่อสำเร็จ"
3. กด **บันทึกและไปต่อ**
4. หน้า Pairing: กรอก **Pairing Code** (จาก Admin → Screens)
5. กด **เชื่อมต่อจอ** → จอจะเข้าสู่หน้าแสดงผลเต็มจออัตโนมัติ 🎉

**ครั้งต่อๆ ไป:** เปิดแอป → เข้าแสดงผลทันที (จำค่าไว้แล้ว)

---

## 4. การใช้งานประจำวัน

| สิ่งที่ทำ | วิธี |
|---|---|
| เปิดจอให้แสดงผล | เปิดทีวี → เปิดแอป NextGen Signage Player (ถ้ายังไม่ตั้ง auto-start) |
| เปิดเมนู kiosk | กดปุ่ม **แดง (Red)** หรือ **Back** บนรีโมท |
| รีโหลดหน้าแสดงผล | เมนู → รีโหลดหน้าแสดงผล |
| เปลี่ยนจอ/จับคู่ใหม่ | เมนู → จับคู่กับจอใหม่ |
| ออกจากแอป | เมนู → ออกจากแอป |

> จอจะแสดงผลต่อเนื่องแม้เน็ตหลุด (เล่นจากแคช) และรีโหลดเองเมื่อเน็ตกลับมา

---

## 5. เปิดแอปอัตโนมัติเมื่อเปิดทีวี

- **ทีวี consumer (webOS ปกติ):** เปิดเองอัตโนมัติไม่ได้ถ้าไม่ root
  → เปิดแอปด้วยรีโมทหลังเปิดทีวี (หรือให้ทีมพัฒนาตั้ง root + auto-start — ดู `scripts/autostart-root.sh`)
- **ทีวี commercial (รุ่น signage/enterprise):** ใช้โหมด SI/SuperSign ของ LG ตั้ง auto-launch ได้เลย

## 6. ข้อควรระวัง

| เรื่อง | คำอธิบาย |
|---|---|
| **Dev Mode ต้องเปิดค้างไว้** | ปิด/หมดอายุ = แอปหาย ต้องติดตั้งใหม่ |
| **Screensaver** | webOS 6.0+ ปิดผ่าน settings ไม่ได้ — **วิดีโอเต็มจอ** จะกัน screensaver ให้อัตโนมัติ (เพลย์ลิสต์ควรมีคลิป) |
| **1 code = 1 device** | จอที่เพิ่งจับคู่ไป จะจับคู่ซ้ำไม่ได้ภายใน ~2 นาที (ต้อง unpair ใน Admin หรือรอ) |
| **จอขึ้น "ออฟไลน์" ใน Admin** | ปกติถ้าจอปิดอยู่ หรือไม่มีเน็ต — จอจะกลับเป็นออนไลน์เองเมื่อเปิด+ต่อเน็ต |
| **เปลี่ยน password admin** | ไม่กระทบจอ (จอใช้ display token แยก) |

## 7. ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| หน้าแรกไม่ขึ้น "เชื่อมต่อสำเร็จ" | เช็ค IP/URL ถูกต้อง + จอและ server อยู่เครือข่ายเดียวกัน |
| หน้าจอว่าง/ดำ | เปิดเมนู (ปุ่มแดง) → รีโหลดหน้าแสดงผล |
| ขึ้น "Invalid pairing code" | กรอกรหัสผิด หรือรหัสเปลี่ยน — ขอ code ใหม่จาก Admin |
| ขึ้น "already paired and active" | จอถูกจับคู่ไปแล้ว — ให้ Admin unpair ก่อน หรือรอ ~2 นาที |
| แอปหายจากหน้า Home | Dev Mode ปิด/หมดอายุ — เปิดแอป Developer Mode → ต่ออายุ แล้วติดตั้งใหม่ |
| จอเข้า screensaver | เพิ่มคลิปวิดีโอในเพลย์ลิสต์ (ดูข้อ 6) |
| ใช้ HTTPS แต่เปิดไม่ได้ | ติดตั้ง CA บนทีวี (Settings → General → Certificates) หรือใช้ HTTP ใน LAN |
| เปิดแอปแล้วเด้งออก | เปิด Developer Mode ค้างไว้ให้ ON |
