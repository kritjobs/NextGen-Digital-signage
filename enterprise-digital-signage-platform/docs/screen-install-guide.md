# 📺 คู่มือติดตั้งจอแสดงผล (ฉบับช่าง/ลูกค้า)

คู่มือนี้สำหรับ **คนที่ไม่ได้เป็นโปรแกรมเมอร์** — ทำตามทีละขั้นได้เลย
จบแล้วจอจะแสดงเนื้อหา (ภาพ/วิดีโอ/เมนู) อัตโนมัติเหมือนทีวีธรรมดา

---

## 0. สิ่งที่ต้องเตรียม

| ของ | มีที่ไหน |
|---|---|
| **จอ** (TV ที่เปิดเว็บได้ — Android TV / จอ Windows / ติดตั้ง Chrome ได้) | ของลูกค้า |
| **รหัสจับคู่ (Pairing Code)** 4 หลัก เช่น `PAIR-8899` | ขอจากผู้ดูแลระบบ (Admin) |
| **ที่อยู่ของระบบ (URL)** | ดูข้อ 1 ด้านล่าง — เลือกโหมดก่อน |
| เครือข่าย (Wi-Fi/สายแลน) ที่เชื่อมถึง server ได้ | ของลูกค้า |

---

## 1. เลือกโหมดก่อน (ถาม Admin ว่าใช้โหมดไหน)

> **สั้นๆ:** ระบบมี 2 โหมด — ถ้าไม่แน่ใจ ให้เลือก **โหมด A (ง่ายสุด)**

| | **โหมด A — HTTP** (แนะนำ) | **โหมด B — HTTPS** |
|---|---|---|
| เหมาะกับ | จอติดตั้งภายในอาคาร (LAN ปกติ) | ต้องการเล่นต่อแม้เน็ตหลุด / เข้าจากนอก |
| ติดตั้งยาก | ⭐ ง่ายมาก — เปิด URL อย่างเดียว | ต้องติดตั้ง **CA** 1 ครั้งต่อจอ |
| URL ที่เปิด | `http://<IP>:3100/pair` | `https://<IP>/pair` |
| หมายเหตุ | จอเล่นได้แม้อินเทอร์เน็ตหลุด (สื่ออยู่ในระบบ) | จอแคชข้อมูล+สื่อ เล่นต่อได้แม้ติดต่อ server ไม่ได้ |

> ถ้า Admin บอกว่า "ใช้ https" → ทำโหมด A ไปก่อนให้จอเล่นได้ แล้วค่อยทำขั้นตอน CA (ข้อ 3 ของโหมด B)
> **IP ของ server** เช่น `10.70.0.1` — ขอจาก Admin

---

## 2. โหมด A — ติดตั้งแบบง่าย (HTTP)

### ขั้นที่ 1 — ต่อจอเข้ากับเครือข่าย
- ต่อ Wi-Fi หรือสายแลนที่อยู่**เครือข่ายเดียวกับ server** (ถาม Admin)
- เช็คว่าจอต่อเน็ตได้จริง (เปิดเว็บอะไรก็ได้ ดูว่าขึ้นไหม)

### ขั้นที่ 2 — เปิดเว็บเบราว์เซอร์บนจอ
- Android TV: เปิดแอป **Browser** (เช่น TV Bro / Chrome / WebView)
- Windows: เปิด Chrome/Edge

### ขั้นที่ 3 — เปิดหน้า "จับคู่จอ"
พิมพ์ URL (ตามที่ Admin ให้) เช่น:
```
http://10.70.0.1:3100/pair
```

**📸 หน้าจอควรแสดง:** หน้าโลโก้ "ThaiHua Digital Signage" + ช่องใส่รหัส + ปุ่ม "Enter" — ไม่มีคำเตือนใดๆ

### ขั้นที่ 4 — ใส่รหัสจับคู่
- พิมพ์รหัสที่ Admin ให้ เช่น `PAIR-8899` → กด **Enter**
- **📸 ควรเห็น:** ข้อความ "จับคู่สำเร็จ" และจอเด้งไปหน้าแสดงผล (จอฟ้า-ดำ มีข้อความ "Display Ready")

### ขั้นที่ 5 — คลิกเพื่อเข้าเต็มจอ
- คลิก/แตะตรงกลางจอ (ข้อความ "Click anywhere to enter fullscreen")
- **📸 ควรเห็น:** เนื้อหา (ภาพ/วิดีโอ) แสดงเต็มจอ

### ✅ เสร็จสิ้น — จอจะแสดงเนื้อหาอัตโนมัติ
- ถ้าจอขึ้นภาพ/วิดีโอแล้ว = **ติดตั้งสำเร็จ** 🎉
- จอจะ refresh เนื้อหาเองทุก 30 วินาที ไม่ต้องยุ่งอีก

---

## 3. โหมด B — HTTPS (เพิ่มขั้นตอนติดตั้ง CA ครั้งเดียว)

> ทำขั้นที่ 1–5 ของโหมด A ก่อน (ใช้ URL `https://<IP>/pair`) — ระหว่างนั้นเบราว์เซอร์อาจเตือนความปลอดภัย **ยังไม่ต้องตกใจ** ทำขั้นตอนนี้ต่อ

### คำเตือนที่อาจเจอ (ปกติสำหรับโหมด B)
**📸 หน้าจอควรเห็น:** หน้า "การเชื่อมต่อของคุณไม่เป็นส่วนตัว / Your connection is not private"
→ นี่คือจุดที่ต้องติดตั้ง CA (ข้างล่าง) — ทำเสร็จแล้วเตือนจะหายไป

### ขั้นที่ 6 — ติดตั้ง CA (ครั้งเดียวต่อจอ)

**ถ้าจอเป็น Windows:**
1. copy ไฟล์ `caddy-root-ca.crt` ไปที่จอ (อยู่ที่ server: `\\10.70.0.1\c\signage\caddy\caddy-root-ca.crt` หรือขอจากช่าง)
2. ดับเบิลคลิกไฟล์ → กด **Install Certificate…** → **Local Machine** → Next
3. เลือก **Place all certificates in the following store** → **Browse…** → **Trusted Root Certification Authorities** → OK → Finish
4. ปิดเบราว์เซอร์ทั้งหมด แล้วเปิดใหม่ → เข้า URL อีกครั้ง → คำเตือนควรหายไป

**ถ้าจอเป็น Android TV — ทางเลือกเรียงตามง่ายสุด:**

✅ **ดีที่สุด — ใช้ native player (`android-player/`):** CA ฝังในแอปแล้ว → ตั้ง Server URL เป็น `https://<IP>` → ใช้ได้เลย **ไม่ต้องติดตั้ง CA ที่จอ**

ถ้าใช้ browser ทั่วไป:
1. **วิธี ADB (เร็วสุด):** ที่จอเปิด Developer Options → **USB/Network debugging** → ที่คอมรัน `caddy\push-ca-adb.bat` → กรอก IP จอ → กด OK ที่จอ (ครั้งเดียว)
2. **วิธี USB:** copy ไฟล์ `caddy-root-ca.crt` ไปที่จอ (USB / แชร์ไฟล์) → **Settings → Security → CA certificates → Install** → เลือกไฟล์ `.crt` → ยืนยัน
3. เปิด browser ใหม่ → เข้า URL อีกครั้ง → คำเตือนควรหายไป

### ขั้นที่ 7 — ตรวจว่า CA ทำงาน
- เปิด `https://<IP>` → **📸 ควรเห็น:** ไม่มีคำเตือนอีกแล้ว เปิดหน้า login ได้ตรงๆ

### ✅ เสร็จสิ้น — โหมด B พร้อมใช้ (จอแคชเนื้อหา เล่นต่อได้แม้เน็ตหลุด)

---

## 4. ตรวจความเรียบร้อย (ใช้ได้ทั้ง 2 โหมด)

| ตรวจ | วิธี | ควรเห็น |
|---|---|---|
| จอแสดงเนื้อหา | มองจอ | ภาพ/วิดีโอเล่นวนไปเรื่อยๆ |
| จอขึ้นในระบบ | ดูหน้า Admin → จอทั้งหมด | จอของเรา **online** (จุดเขียว) |
| (โหมด B) แคชทำงาน | ต่อท้าย URL หน้ากิโอสก์ด้วย `&simoffline=1` | แถบทอง **"⚡ OFFLINE — เล่นจากแคช"** ที่มุมขวาบน |

## 5. ปัญหาที่พบบ่อย (แก้เองได้)

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| เปิด URL ไม่ขึ้น / ไม่มีอะไรเลย | จออยู่นอกเครือข่าย server / พิมพ์ URL ผิด | เช็ค Wi-Fi/สายแลน + พิมพ์ URL ใหม่ (มี `:3100` ครบในโหมด A) |
| "การเชื่อมต่อของคุณไม่เป็นส่วนตัว" | โหมด B ยังไม่ติดตั้ง CA (หรือติดตั้งตัวเก่า) | ทำขั้นที่ 6 ใหม่ — ต้องเป็นไฟล์ CA **ปัจจุบัน** |
| ใส่รหัสแล้วขึ้น "รหัสผิด" | พิมพ์รหัสผิด / หมดอายุ | ขอรหัสใหม่จาก Admin |
| จอค้าง "Display Error" | token เก่าหมดอายุ | ให้ Admin generate token ใหม่ (หน้า Admin → จอ → สร้างลิงก์) |
| จอไม่เปลี่ยนเนื้อหา | ยังไม่มี schedule/playlist กำหนดให้จอ | แจ้ง Admin ไปกำหนดเนื้อหาให้จอ |
| เปิดจอแล้วเป็นจอฟ้า (Offline banner ทอง) | จอติดต่อ server ไม่ได้ชั่วคราว | เช็คสาย/สัญญาณ — จอจะกลับมาเองเมื่อต่อได้ (โหมด B จะเล่นจากแคชระหว่างนั้น) |

## 6. (สำหรับช่าง) เปลี่ยนโหมด HTTP ↔ HTTPS

ที่เครื่อง server (`C:\signage\caddy\`):

1. เปิดไฟล์ `mode.conf` — แก้เป็นบรรทัดเดียว: `http` หรือ `https`
2. รัน `switch-mode.bat`
3. หลังเปลี่ยน: URL ที่ใช้กับจอ = 
   - `http` → `http://<IP>:3100/pair`
   - `https` → `https://<IP>/pair`

> จอที่ผูกไปแล้ว**ไม่ต้องตั้งใหม่** — ระบบรองรับทั้ง 2 โหมดพร้อมกัน
> เปลี่ยนโหมดไม่ต้องแก้โค้ด ไม่ต้อง deploy (เฉพาะ server เวอร์ชันล่าสุดที่ผ่าน redeploy แล้ว)

## 7. ใครทำอะไร (แบ่งหน้าที่)

| บทบาท | หน้าที่ |
|---|---|
| **ช่าง/ผู้ติดตั้ง** | เลือกโหมด (A/B) → ต่อจอเน็ต → เปิด URL → ใส่รหัส → (โหมด B) ติดตั้ง CA |
| **Admin** | สร้างจอในระบบ → ให้รหัสจับคู่ + URL → กำหนด playlist/schedule → generate token ใหม่เมื่อจอ error |
| **ลูกค้า** | แค่เปิดจอทิ้งไว้ — เนื้อหาแสดงเองอัตโนมัติ |
